2. Mục tiêu thực hành

Triển khai ứng dụng Hello Cloud API bằng Node.js và Express trên GitHub Codespaces. Quan sát tài nguyên đám mây và đối chiếu với 5 đặc tính điện toán đám mây của NIST.

4. Năm đặc tính điện toán đám mây NIST

  1. On-demand self-service: Sinh viên tự tạo Codespace trên GitHub mà không cần nhân viên quản trị cấp máy.
  2. Broad network access: API có thể được truy cập bằng trình duyệt trên laptop và điện thoại qua Internet.
  3. Resource pooling: GitHub cung cấp môi trường tính toán từ hạ tầng tài nguyên dùng chung, sinh viên không phải chọn máy chủ vật lý cụ thể.
  4. Rapid elasticity: Dịch vụ đám mây cho phép điều chỉnh tài nguyên linh hoạt theo nhu cầu. Bài thực hành mới minh họa bước cấp phát nhanh, chưa kiểm chứng trực tiếp khả năng tự co giãn.
  5. Measured service: Mức sử dụng Codespaces được theo dõi qua Billing Usage, gồm tài nguyên tính toán và lưu trữ.

5. Kết quả thực hành

Đã xây dựng Hello Cloud API để hiển thị hostname, hệ điều hành, CPU, RAM, uptime và thời gian của môi trường chạy.

Đã kiểm tra truy cập từ điện thoại và chuyển cổng về Private sau khi thử nghiệm.

Thời gian cấp phát Codespace: Điền số giây/phút đo được.

6. Kết luận

GitHub Codespaces giúp chuẩn bị môi trường lập trình từ xa, giảm nhu cầu cài đặt trực tiếp trên máy cá nhân và hỗ trợ truy cập ứng dụng qua Internet.
